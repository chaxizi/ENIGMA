## 核心验证

- 非默认环位、转子 II/IV/V、十对插线，WXC 起点的 BLA → KCH，以及反向还原。
- 同配置在 BLA 起点的历史长消息 → NIBLFMYMLLUFWCASCSSNVHAZ，以及反向还原。
- 编码前先步进；ADU → ADV → AEW → BFX 双步进序列。
- 缺口判断不随环位额外平移；两个进位条件同时满足时，中转子只前进一步。
- 正反接线、反射器对称性、无自身加密、状态隔离与只读输入。
- 非法和稀疏配置、位置回绕、空输入、Unicode 与 UTF-16 上限。

## 操作与浏览器验证

- 输入、删除、混合文字、屏幕键盘追加和清空。
- 配置草稿不影响现有结果；应用后保留输入并从初始位置重算。
- 转子交换时环位和初始位置跟随转子移动。
- 插线的自身连接、重复使用与十对上限；移除连接。
- 中文输入法组合输入期间不转换，提交后处理。
- 超长编辑和粘贴整次拒绝，保留先前文本。
- 剪贴板成功与拒绝时的手动复制；完整 Unicode 输出。
- 在消息中间输入小写字符后，光标保持原编辑位置。
- 连续快速点击六十次，输入完整且输出长度正确。
- 消息编辑、复制、输出、屏幕键盘的 Tab 焦点顺序；回车操作。
- 刷新清空会话，存储为空，输入与配置不触发网络请求（允许浏览器延迟请求本地 favicon）。
- 减少动态效果偏好生效。

## 性能

首次验证中，预热后处理 10,000 个英文字母的记录为 **5.202ms**，通过小于 100ms 的目标。该结果仅表示测试环境中的核心运算时间，不包含网页绘制，也不代表所有手机的速度。性能测试只输出字符数与耗时，不输出硬件型号或系统构建。

- 移动端使用浏览器模拟，未进行实体 iPhone/Android 设备测试。
