# Enigma v1.0 实施基线

## 已确认范围

准确模拟与操作优先，纯前端本地运算，简体中文。使用三转子 Enigma I、I–V 转子、固定反射器 B，提供环位、初始位置及最多十对插线。默认 I/II/III，01/01/01，AAA，无插线。

不包含账号、后端、云存档、分享链接、关卡、自动破解、其他型号、完整信号路径、音效和公开发布。

## 系统标准

- React + TypeScript + Vite，CSS Modules 与 CSS 变量，React reducer 管理会话。
- 核心独立于页面，数据只读，接口不修改输入对象。
- 已应用配置、配置草稿、运行结果分离；结果由当前消息和已应用配置派生。
- 数据与界面统一按操作者视角左、中、右排列，内部字母/位置/环位为 0–25。
- 编码前先步进，支持中间转子双步进；窗口进位条件不随环位额外平移。
- 转子交换时，对应的环位和初始位置随之交换。
- 只转换 ASCII 字母，其他字符不变且不步进；所有编辑从初始位置重算。
- 输入上限 10,000 个 UTF-16 单元，整次拒绝超限输入，不静默截断。
- 组合输入期间暂缓规范化与运算；屏幕键盘禁用至组合输入结束。
- 不存储会话，不向网络、地址栏或日志写入消息。

## 界面标准

深色机身、黄铜细节、暖色输出灯；配置与消息使用浅色纸面。仅使用系统字体、本地 SVG 与 CSS。桌面双栏，移动单栏，移动配置默认折叠。移动阅读顺序为转子、消息、灯板键盘、配置、说明。

实体键盘在输入框正常工作；屏幕键盘追加至末尾；灯板保留最后一个已转换字母的输出。所有控件可通过键盘访问，焦点清楚，减少动态效果设置生效。常用触控区域目标至少 44px，窄屏键盘局部横向滚动以保持 44×44px 按键，不造成整页横向溢出。

## 实施与验收顺序

1. 工程初始化、锁定兼容依赖、整理规则与接线来源。
2. 核心、固定向量、进位与边界测试。
3. 配置、消息编辑、复制、清空与恢复默认流程。
4. 仪器视觉、移动布局、可访问性和动效。
5. 类型/静态检查、单元/组件测试、跨浏览器测试、性能记录、生产构建。

各阶段结果见 VALIDATION.md。历史样例与结构性测试必须同时通过，不能仅凭往返还原证明正确。浏览器检查覆盖 Chromium、Firefox、WebKit 和 375px 布局，含 IME、超长输入、剪贴板失败、刷新和隐私。
