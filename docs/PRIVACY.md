## 上传边界

使用 Git 提交时需保留 `.gitignore`；若手动网页上传，应只选择已检查的源码和文档，不要拖入整个工作目录。`.gitignore` 不会清理已经提交过的内容，也不会过滤网页手动上传的文件。

Git 提交的作者与提交者姓名、邮箱是源码之外的公开信息。此次发布使用公开 GitHub 用户名及对应的 GitHub noreply 邮箱，不写入真实姓名、真实邮箱或本机用户名。后续提交应继续检查这些字段。

远程建库时生成的许可证曾包含个人姓名。经仓库所有者确认，此次发布使用不继承该初始提交的新历史，许可证改用项目署名。改写分支历史不会保证删除已经被复制、缓存或通过旧提交链接访问的内容；如需移除 GitHub 上仍可访问的旧对象，应按平台流程另行处理。

之后新增截图、环境文件、测试跟踪、日志、部署配置或 Git 提交历史时，需要重新检查。网站托管服务、浏览器扩展、操作系统剪贴板及后续第三方集成不在本次应用代码检查范围内。
